# Vivek V Ron - AI/ML Engineer Portfolio

Welcome to my personal portfolio and CMS platform.

## Features
- **3D Interactive Canvas:** Implemented using Three.js and React Three Fiber.
- **Custom Content Management System (CMS):** A bespoke `/admin` portal allowing real-time edits to projects, hackathons, and certifications without redeploying.
- **Supabase Integration:** Uses PostgreSQL and Supabase for persistent storage.
- **Animated UI:** Built with Framer Motion, Tailwind CSS, and Radix UI.

## Local Setup
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Configure `.env.local` with Supabase keys.
4. Run `npm run dev` to start the Next.js server.
